# Student To-Do List — HTML

This folder contains the HTML structure for the `student-todo-list` project.

## File
- `index.html` — basic webpage structure for a student task list.

## How to view
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

This is the HTML-only starter version. The Add Task button is a placeholder; interactive task features will need JavaScript, and styling can be added with CSS.
